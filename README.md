# Manhwa Hybrid Recommendation Engine

A low-latency recommendation engine built with Python and Streamlit that combines **Sentence-BERT embeddings** with **offline batch pre-computation** and **dynamic multi-feature re-ranking**.

---

##  System Design

The application uses a **Two-Stage Hybrid Architecture**:

1. **Stage 1: Candidate Retrieval (NLP Similarity)**  
   Retrieves the top 100 candidates using pre-computed dense semantic vectors generated by Sentence-BERT.
2. **Stage 2: Live Multi-Feature Re-Ranking**  
   Applies publication status filters and re-ranks candidate titles live using a weighted formula:

$$\text{Final Score} = (w_{\text{sim}} \times \text{sim-}_{\text{score}}) + (w_{\text{score}} \times \text{}_{\text{score}}) + (w_{\text{pop}} \times \text{}_{\text{popularity}})$$

---

## Key Challenges & Solutions

* **Inference Latency (Pre-Computation)**  
  * *Problem:* Generating BERT embeddings and calculating a $5000 \times 5000$ matrix on live user requests took several minutes on CPU.
  * *Solution:* Shifted matrix generation offline (`precompute.py`). The resulting matrix binary (`cosine_sim.npy`) is loaded directly into RAM via Streamlit caching in $<100\text{ ms}$.

* **Mathematical Weight Distortion**  
  * *Problem:* Community ratings ($0–100$) dominated similarity scores ($0.0–1.0$), making weight adjustments unresponsive
  * *Solution:* Normalized rating and popularity columns to a $0.0–1.0$ boundary using Scikit-Learn's `MinMaxScaler`.
